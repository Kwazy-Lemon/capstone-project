## Interface Names and Input/Output Conventions

### 1. Shared Mathematical and Data Conventions

The package uses

\[
Gx(t)+M\frac{dx(t)}{dt}=b(t).
\]

Let `N` be the number of unknowns, `K` the number of frequency points, and `S` the number of timesteps.

| Name | Shape or type | Physical meaning or purpose |
|---|---|---|
| `G` | `N × N` numerical matrix, converted to CSC sparse format in the solver | Static MNA coefficients, including resistor terms and source constraints; not every entry is a conductance |
| `M` | `N × N`, matching `G` | Dynamic terms, including capacitor and inductor contributions |
| `b_dc` | Length `N` | DC source vector; KCL rows typically contain injected currents, while voltage-source constraint rows contain voltages |
| `b_ac` | Length `N`, possibly complex | AC source phasors; this interface uses the same source vector throughout the sweep |
| `source_at` | Callable with the form `source_at(t)` | Takes time as input and returns the current real-valued source vector of length `N` |
| `x0` | Length `N`, real-valued | Initial state satisfying the specified stored-energy conditions and algebraic constraints |
| `x` | NumPy array with `shape == (N,)` | All unknowns at one operating point or one frequency |
| `X` | Two-dimensional array | States at multiple frequencies or times, with one solution per row |

Use SI units: resistance in Ω, capacitance in F, inductance in H, time in s, frequency in Hz, and current in A. `1e3` means 1000; `1e-6` means 0.000001, so `C=1e-6` represents 1 µF.

The state vector `x` contains both voltages and selected branch currents, so its entries have different units. Different rows of `G` and `b` also have different physical units. Do not label the entire matrix or vector simply as “conductance” or “current.”

### 2. The Three Public Solver Interfaces

#### `dc_solve(G, b_dc)`

| Item | Description |
|---|---|
| File | `linear_solvers.py` |
| Example call | `x_dc = dc_solve(G, b_dc)` |
| Inputs | Static matrix `G` and DC source vector `b_dc` |
| Output | A solution vector of length `N`, ordered to match the matrix columns |
| Calculation | Solves `G @ x_dc = b_dc` |
| Internal call | `solve_checked(G, b_dc)` |

The derivative is zero at DC steady state, so this interface does not take `M`. For inductors, the DC short-circuit constraint must still be included in `G`.

#### `ac_sweep(G, M, b_ac, frequencies_hz)`

| Item | Description |
|---|---|
| File | `linear_solvers.py` |
| Example call | `X_ac = ac_sweep(G, M, b_ac, frequencies_hz)` |
| Inputs | `G`, `M`, a fixed AC source-phasor vector, and a one-dimensional array of positive frequencies `frequencies_hz` |
| Output | A complex two-dimensional array with `shape == (K, N)` |
| Calculation | For each `f`, solves `(G + 1j*2*pi*f*M) @ x = b_ac` |
| Internal calls | One call to `solve_checked()` per frequency |

Row `k` corresponds to `frequencies_hz[k]`. The frequency array must be nonempty, finite, and strictly positive; its input order is preserved. The function returns only `X_ac`, so the caller retains the frequency array. `run_ac()` computes gain and phase and handles plotting and file output.

#### `backward_euler(G, M, source_at, x0, dt, tstop)`

| Parameter | Description |
|---|---|
| `G`, `M` | The two matrices of a linear, time-invariant circuit |
| `source_at` | A function returning the real source vector at a given time; do not pass a plain array as though it were a function |
| `x0` | Initial state; the caller is responsible for physical consistency |
| `dt` | Positive fixed timestep in seconds |
| `tstop` | Positive end time in seconds; the current implementation requires an integer multiple of `dt`, allowing floating-point rounding error |

Call and return values:

```python
t, X_tran = backward_euler(G, M, source_at, x0, dt, tstop)
```

- `t.shape == (S+1,)`, where `S=round(tstop/dt)`.
- `X_tran.shape == (S+1, N)`.
- `t[0]=0` and `X_tran[0]=x0`; the first computed step corresponds to `t[1]=dt`.
- At each new time, the algorithm calls `source_at(t[n])` and adds the history contribution from the previous state.
- Internally, it factors the fixed matrix with `splu()` and calls `lu.solve()`. It does not call `solve_checked()` at each timestep.
- This implementation handles real-valued time-domain states. Use `ac_sweep()` for complex AC phasors.

The initial state's length and finiteness are checked, but the function does not automatically find a consistent `x0` for an arbitrary circuit. If `x0` violates source constraints, KCL, or the specified stored-energy conditions, correct it before simulation.

### 3. Shared Linear-Solver Helper

`solve_checked(A, b)` is defined in `linear_solvers.py`. It:

1. Converts `A` to CSC sparse format and flattens `b` into a one-dimensional array.
2. Checks the square-matrix dimensions, vector length, and presence of `NaN` or infinite values.
3. Calls `spsolve(A, b)` to solve the system.
4. Converts matrix-rank warnings into exceptions and checks that the solution is finite.
5. Returns the solution vector of length `N`.

These are basic input and output checks, not a complete circuit-topology or conditioning analysis. Floating nodes and conflicting ideal-source constraints still need to be addressed during modeling.

## Basic Code Explained Step by Step

### 1. Importing Libraries and Your Own Functions

```python
import numpy as np
from scipy.sparse import csc_matrix
from linear_solvers import dc_solve, ac_sweep, backward_euler
```

- `import numpy as np` imports NumPy under the shorter name `np`, as in `np.array()`.
- `csc_matrix` is a sparse matrix storage format. Large circuit MNA matrices usually contain many zeros, so sparse storage can reduce memory use.
- The last line imports three functions from `linear_solvers.py` in the same folder. `linear_solvers` is our own module, not a third-party package to install using pip.
- NumPy handles arrays and numerical operations; SciPy supplies sparse matrices and solvers; Matplotlib generates plots.

### 2. `def`, Parameters, Return Values, and Calls

```python
def dc_solve(G, b_dc):
    return solve_checked(G, b_dc)

x_dc = dc_solve(G, b)
```

The first line defines a function name and two parameters. At the call site, the variable `b` is passed into the function, where it is referred to by the parameter name `b_dc`. These names do not need to be identical. `return` sends the solution vector back to the caller, where it is assigned to `x_dc`.

This excerpt illustrates the call relationship and assumes that `G`, `b`, and `solve_checked` already exist. Use the complete program for execution.

### 3. Arrays, Indices, and Result Ordering

```python
b = np.array([0, 0, 5.0])
x = dc_solve(G, b)
vin = x[0]
vout = x[1]
i_source = x[2]
```

Here, `b` has shape `(3,)`, meaning a one-dimensional array of length 3. The first two KCL equations have zero right-hand sides; the third equation sets the source voltage to 5 V. The three entries in `x` correspond to the three matrix columns.

| Quantity selected | Python | MATLAB |
|---|---|---|
| First unknown | `x[0]` | `x(1)` |
| Second unknown | `x[1]` | `x(2)` |
| All unknowns at row index n, using each language's own indexing convention | `X[n, :]` | `X(n, :)` |
| Second unknown at all times or frequencies | `X[:, 1]` | `X(:, 2)` |

The colon `:` selects all entries along that dimension. For example, `X[:,1]` selects the second column across all rows. It represents `V_out` only for the unknown ordering used in this example.

`np.asarray(b).reshape(-1)` converts the input into a one-dimensional array. Here, `-1` asks NumPy to infer the length from the number of elements; it does not select the last element. Applying `.T` to a one-dimensional array leaves it one-dimensional. Use `reshape(-1,1)` if an actual column array is needed, although this package's solvers consistently use vectors with shape `(N,)`.

### 4. Matrix Multiplication, Linear Solves, and Complex Numbers

| Code | Meaning |
|---|---|
| `G @ x` | Matrix-vector multiplication, corresponding to Gx |
| `G @ x - b` | Equation residual; a value close to zero indicates that the computed solution satisfies the assembled equations |
| `spsolve(G, b)` | Finds x satisfying Gx=b; does not return the inverse of G |
| `G + 1j*omega*M` | Complex AC coefficient matrix; `1j` is the imaginary unit |
| `np.abs(H)` | Magnitude of the complex transfer function |
| `np.angle(H, deg=True)` | Phase angle in degrees |
| `np.vstack([x1, x2, ...])` | Stacks solution vectors as rows of a two-dimensional result array |

For an ordinary NumPy `ndarray`, `*` is elementwise multiplication and `@` is matrix multiplication. The meaning of `*` for some SciPy sparse types differs from its meaning for an ndarray. This package therefore writes matrix multiplication explicitly with `@` and uses `*` for scalar multiplication where appropriate.

MATLAB's `G \ b` solves the linear system. MATLAB's `.'` performs a plain transpose, while `'` performs a conjugate transpose. These can produce different results for complex AC quantities.

### 5. From AC Matrices to a Frequency-Response Plot

```python
f = np.unique(np.r_[np.logspace(0, 5, 301), fc])
X = ac_sweep(G, M, np.array([0, 0, 1.0]), f)
H = X[:, 1] / X[:, 0]
gain_dB = 20*np.log10(abs(H))
phase_deg = np.angle(H, deg=True)
```

1. `np.logspace(0,5,301)` generates 301 logarithmically spaced frequencies from 10⁰ Hz to 10⁵ Hz.
2. `np.r_[...,fc]` adds the analytical cutoff frequency; `np.unique()` sorts the values and removes duplicates.
3. `ac_sweep()` returns the full solution at every frequency. In this example, adding fc gives 302 frequency points and a result of shape `(302,3)`.
4. The second column is the output and the first is the input. Dividing them frequency by frequency gives `H=Vout/Vin`.
5. Gain and phase are computed from H, and `run_ac()` saves the table and plot.

### 6. Time-Dependent Sources: Why `lambda` Appears

```python
source = lambda t: np.array([0, 0, Vs])
```

This is a short function definition, equivalent to:

```python
def source(t):
    return np.array([0, 0, Vs])
```

`backward_euler()` needs a function that returns the source vector at a requested time. This example begins just after the step at t=0+, and the voltage remains Vs afterward. The function therefore accepts `t` without using it. For a time-varying source, replace `Vs` with the appropriate time-dependent expression and check the initial conditions again.

### 7. Backward Euler History Terms and LU Factorization

```python
history_matrix = M / dt
A = (G + history_matrix).tocsc()
lu = splu(A)
for n in range(1, steps + 1):
    b = np.asarray(source_at(t[n]), dtype=float).reshape(-1)
    X[n] = lu.solve(b + history_matrix @ X[n - 1])
```

- `history_matrix` is M/Δt in the equation.
- `A` is the fixed left-hand-side matrix G+M/Δt.
- `splu(A)` performs a sparse LU factorization once. Each subsequent step reuses that factorization to solve a new right-hand side.
- `range(1,steps+1)` covers 1 through steps. Row 0 already contains the initial state and must not be treated as the first computed step.
- `X[n-1]` is the known previous state. Multiplying it by M/Δt provides the history contribution.
- `lu.solve(...)` returns the current solution, which is stored in row n.

The same factorization can be reused throughout the loop only while the linear matrices and timestep remain unchanged. Adaptive timesteps or nonlinear iteration would require the coefficient matrix and factorization to be updated accordingly.

`np.empty()` allocates storage without initializing the entries to zero. The implementation first writes `X[0]`, then fills each subsequent row before using it.

## 2. Task 3: Linear DC Benchmark

### Objective

Use a linear circuit with a known solution to check the node voltages and branch currents computed by Python. Then compute the same circuit independently in MATLAB and compare the results. Here, a benchmark primarily establishes correctness, rather than only measuring execution speed.

The sequence is: define the circuit and reference directions → write KCL and voltage-source constraints → assemble the matrix → solve in Python → independently assemble and solve in MATLAB → compare voltages, currents, and equation residuals.

### Main Example: Resistor Divider

| Component | Positive terminal or start node | Negative terminal or end node | Value |
|---|---|---|---|
| V1 | in | ground | 5 V |
| R1 | in | out | 1 kΩ |
| R2 | out | ground | 2 kΩ |

The unknown vector is

\[
x=\begin{bmatrix}V_{in}\\V_{out}\\I_{V1}\end{bmatrix}.
\]

The three equations are KCL at the input node, KCL at the output node, and the voltage-source constraint:

\[
\frac{V_{in}-V_{out}}{R_1}+I_{V1}=0,
\]
\[
\frac{V_{out}-V_{in}}{R_1}+\frac{V_{out}}{R_2}=0,
\]
\[
V_{in}=5.
\]

Minimal MATLAB implementation:

```matlab
R1 = 1000; R2 = 2000;
G = sparse([1/R1, -1/R1, 1;
            -1/R1, 1/R1+1/R2, 0;
            1, 0, 0]);
b = [0; 0; 5];
x = G \ b;
IR1 = (x(1)-x(2))/R1;
IR2 = x(2)/R2;
```

The corresponding Python call is `x = dc_solve(G, b)`, which uses SciPy's sparse linear solver internally. MATLAB's `G \ b` and Python's `spsolve(G, b)` both solve `G*x=b` without explicitly forming the inverse matrix.

| V_out | 3.3333333333 V |
| I_R1, in → out | 1.6666666667 mA |
| I_R2, out → ground | 1.6666666667 mA |
| I_V1, in → ground | −1.6666666667 mA |

The source current is negative because the actual current leaves the source's positive terminal, while the chosen positive reference direction enters that terminal.

## 3. Task 4A: AC Frequency Response

### Objective and Governing Equation

Compute the steady-state sinusoidal response of a linear circuit at different frequencies.

Starting from

\[
Gx(t)+M\frac{dx(t)}{dt}=b(t),
\]

use the `exp(jωt)` phasor convention, under which differentiation becomes multiplication by `jω`:

\[
(G+j\omega M)X=B_{AC},\qquad\omega=2\pi f.
\]

Here, `f` is in Hz and `ω` is in rad/s. `M` is the dynamic matrix containing capacitor and inductor terms; a scalar capacitance C cannot replace the entire matrix. If the team calls this matrix `Cmat`, that name can be used as long as its physical definition and signs match.

### RC Validation Circuit

| Component | Connection | Value |
|---|---|---|
| V1 | in → ground | AC phasor 1 V |
| R | in → out | 1 kΩ |
| C | out → ground | 1 µF |

This circuit differs from the DC divider: the output-to-ground resistor R2 has been replaced by a capacitor.

The core MATLAB loop is:

```matlab
for k = 1:numel(f)
    omega = 2*pi*f(k);
    xAC = (G + 1i*omega*M) \ bAC;
    H(k) = xAC(2)/xAC(1);
end
gain_dB = 20*log10(abs(H));
phase_deg = angle(H)*180/pi;
```

- `xAC` contains complex phasors, representing both magnitude and phase.
- `H=Vout/Vin` is a dimensionless transfer function. The numerical output phasor equals H when the input phasor is 1 V with zero phase, as in this example.
- `20*log10(abs(H))` expresses the voltage ratio in dB.
- This example's phase ranges from 0° to −90°. More complex circuits may require `unwrap` for a continuous phase display.

The independent analytical reference is

\[
H(j\omega)=\frac{1}{1+j\omega RC},\qquad f_c=\frac{1}{2\pi RC}=159.154943\ \mathrm{Hz}.
\]

At the cutoff frequency, the magnitude is `1/sqrt(2)`, the gain is approximately −3.0103 dB, and the phase is −45°. The code explicitly adds the cutoff frequency to the sweep, rather than treating a nearby sample as the exact cutoff point.

This is linear AC analysis. Extending it to diode or MOSFET small-signal AC requires a DC operating point followed by linearization using device derivatives. Simply applying this formula to the original nonlinear circuit is insufficient.

## 4. Task 4B: Backward Euler Transient Analysis and Error Table

### From a Differential Equation to a Linear System at Each Step

Backward Euler approximates the derivative at the current time using the current and previous states:

\[
\left.\frac{dx}{dt}\right|_{t_n}\approx\frac{x_n-x_{n-1}}{\Delta t}.
\]

Substitute this into `G*x + M*dx/dt=b`:

\[
Gx_n+M\frac{x_n-x_{n-1}}{\Delta t}=b(t_n).
\]

Move the known previous-state contribution to the right-hand side:

\[
\boxed{(G+M/\Delta t)x_n=b(t_n)+(M/\Delta t)x_{n-1}.}
\]

`G+M/dt` is the coefficient matrix for the current step. The history term `M*x_prev/dt` carries the previous capacitor and inductor state. The source vector is evaluated at the current time `t_n`, not the previous time.

Core MATLAB code:

```matlab
A = G + M/dt;
X(1,:) = x0.';                    % Row 1 corresponds to t=0
for n = 2:numel(t)
    rhs = b_at(t(n)) + (M/dt)*X(n-1,:).';
    X(n,:) = (A \ rhs).';
end
```

For fixed timesteps and constant linear matrices, the Python implementation performs one LU factorization and reuses it for different right-hand sides. The MATLAB reference uses the more direct backslash notation.

### Initial Conditions: A Common Source of Errors

Use the same RC circuit with a 0-to-5 V step and an initial capacitor voltage of 0 V. Define t=0 as the instant just after switching, t=0+:

\[
x_0=[5,\ 0,\ -5/R]^T=[5,\ 0,\ -0.005]^T.
\]

The capacitor voltage is still zero, the ideal source node is already at 5 V, and KCL determines the source current. This initial state satisfies both the capacitor's initial condition and the algebraic constraints.

Using the 5 V DC operating point as the initial state would mean the capacitor is already charged to 5 V. It would therefore not produce the intended charging waveform from 0 V.

`X[0]` in Python and `X(1,:)` in MATLAB store the initial state. The first computed state belongs to t=dt. Do not advance one timestep and label that result as t=0.

### Building the Timestep-Error Table

The time constant is `τ=RC=1 ms`, and the simulation runs to `5τ=5 ms`. The continuous-time analytical solution is

\[
V_{out}(t)=5(1-e^{-t/(RC)}).
\]

For each timestep, evaluate the analytical solution at that timestep's own sample times and compute

\[
E_{max}(\Delta t)=\max_n|V_{BE}(t_n)-V_{exact}(t_n)|.
\]

This is the maximum error at the sampled times. All runs use the same initial conditions, source, circuit, and end time. The analytical solution can be evaluated directly on each grid, so no interpolation between coarse and fine grids is needed.

Results obtained from an actual Python run:

| Timestep | Timestep/τ | Number of steps | Maximum voltage error | RMSE | Observed order |
|---:|---:|---:|---:|---:|---:|
| 200 µs | 0.2 | 25 | 0.169991 V | 0.103632 V | — |
| 100 µs | 0.1 | 50 | 0.088319 V | 0.053730 V | 0.9447 |
| 50 µs | 0.05 | 100 | 0.045050 V | 0.027376 V | 0.9712 |
| 25 µs | 0.025 | 200 | 0.022756 V | 0.013820 V | 0.9853 |
| 12.5 µs | 0.0125 | 400 | 0.011437 V | 0.006944 V | 0.9926 |

The order is estimated using `p=log2(E_previous/E_current)` because each timestep is half the preceding one. Values approaching 1 agree with Backward Euler's first-order global error. Stability and accuracy are separate issues: a large timestep can produce a stable waveform with significant numerical error.

The program also uses the exact recurrence solution of the discretized RC problem,

\[
V_n=5\left[1-(1+\Delta t/(RC))^{-n}\right],
\]

to check implementation and time indexing. Comparing with the continuous-time analytical solution then measures time-discretization error. These two checks serve different purposes.
