# DC Analysis Results

This folder contains the results from the Week 1 DC analysis prototype.

## Circuit

The circuit consists of:

- A 10 V independent voltage source
- R1 = 1 kΩ
- R2 = 2 kΩ

## MNA Results

The MATLAB prototype produced the following results:

- Vin = 10.0000 V
- Vout = 6.6667 V
- I_R1 = 3.3333 mA
- I_R2 = 3.3333 mA
- KCL Error ≈ 0 A

The results verify that the MNA formulation correctly solves the DC operating point and satisfies KCL.
